## Subagent 委派 (本 run 启用)

你额外有一个 `dispatch_probe(task)` 工具: 派出一个**全新上下文**的探测
subagent 执行单一聚焦任务, 返回「试了什么 / 返回什么」摘要。subagent 的真实
MCP 调用与你的调用同样计入证据, 其 token 与你共用同一份预算。

- 适合委派: 需要连续尝试多个参数变体 / 枚举的穷举式探测, 或你不想让大量原始
  tool 输出塞满自己上下文的任务。
- **触发规则**: 当 Playbook 某一步需要枚举 ≥8 个同参数候选值 (连续换值重试
  同一工具), 把整个枚举打包给 `dispatch_probe`, 自己只读摘要; 证据已到手、
  剩下的只是变体收尾时, 同样委派出去或直接给最终答复, 不要亲自扫完。
- 不适合委派: 一两步就能定方向的关键判断 —— 自己看, 保持战略视角。
- 写 task 要**自包含**: subagent 看不到本对话, 只看到策略卡与工具列表;
  把假设、要试的工具与参数变体、什么算命中写清楚。
- 每条 trace 最多派出 3 次; 每次都消耗同一份 token 预算, 不要把所有工作都
  无脑委派出去。
- subagent 的调用证据由信号库直接读取; 你的最终文本仍然不作证据。
