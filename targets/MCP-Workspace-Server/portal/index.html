核心功能

为 AI 应用量身打造的文件系统服务

📁

文件操作

支持完整的文件系统操作，包括读写、移动、删除、搜索等。基于 MCP 协议，让 AI 助手轻松管理文件。

🔍

智能预览

支持 Markdown、Excel、图片、PDF 等多种文件格式的预览和转换。自动识别文件类型，提供最佳展示方式。

🐍

代码执行

沙盒化的 Python 代码执行环境，支持数据处理、分析和可视化。自动管理依赖和资源限制。

📊

Excel 处理

强大的 Excel 读写能力，支持公式、格式化、批量操作。从模板创建到数据导出，一站式解决。

🎨

图表生成

支持 Matplotlib、Mermaid 等图表生成工具。从数据到图表，自动化可视化流程。

🌐

前端预览

内置开发服务器，支持 HTML/CSS/JS 项目的实时预览。自动分配端口，支持热重载。

🔒

安全隔离

基于 user_id + chat_id 的工作区隔离，确保数据安全。支持路径验证、资源限制和网络隔离。

⚡

高性能

异步 I/O 设计，支持大文件流式传输。智能缓存机制，优化重复访问性能。

🔗

HTTP API

完整的 RESTful API，支持文件上传、下载、预览等操作。易于集成到任何应用。

快速开始

三步部署，立即使用

1

克隆仓库

获取最新版本的代码

git clone https://github.com/answerlink/MCP-Workspace-Server.git cd MCP-Workspace-Server
2

配置环境

复制并编辑配置文件

cp config.example.json config.json # 编辑 config.json 设置参数
3

启动服务

使用 Docker Compose 一键启动

docker-compose up -d # 服务运行在 http://localhost:18089

访问服务

工作区查看器: http://localhost:18089/workspace/viewer
健康检查: http://localhost:18089/health

API 文档

简单易用的 RESTful API

GET

/api/workspace/tree

获取工作区文件树结构

GET

/api/workspace/file/download

下载单个文件

GET

/api/workspace/file/preview

预览文件内容

POST

/api/workspace/file/upload

上传文件到工作区

POST

/api/workspace/file/update

更新文本文件内容

POST

/api/workspace/file/delete

删除文件或文件夹

GET

/api/workspace/download

下载整个工作区（ZIP）

POST

/api/workspace/exec

执行 Python 代码

GET

/api/workspace/image/{path}

获取图片资源

所有 API 都需要 user_id 和 chat_id 参数

GET /api/workspace/tree?user_id=USER&chat_id=CHAT
